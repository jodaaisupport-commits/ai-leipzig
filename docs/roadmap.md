# Roadmap: ai-leipzig

## Phase 1 – MVP
- Repository klonen
- Lokale Repository-Übersicht
- Fetch / Pull / Commit / Push
- Datei-Explorer
- Texteditor mit Syntaxhervorhebung
- SSH- und Token-Authentifizierung
- Branch erstellen und wechseln
- Einfache Konflikterkennung

## Phase 2 – Produktreife
- Hintergrund-Synchronisierung pro Repository
- Konfigurierbare Trigger
- Wiederholungen bei Netzwerkproblemen
- Backup & Restore
- Verschlüsselte Exporte
- Verbesserte Fehlerberichte und Protokolle

## Phase 3 – Erweiterte Git-Funktionen
- Mehrere Remotes verwalten
- Verbesserte Commit-Historie
- Diff-Ansichten in der App
- Erweiterte Konfliktauflösung
- Grundlegende Unterstützung für ausgewählte Zusatzfunktionen

## Phase 4 – Integrationen & Komfort
- GitHub/GitLab-Integration
- Anzeige von Issues und Pull Requests
- Shortcuts, Widgets oder Automationen je nach Plattform
- Verbesserte Repository-Einstellungen
